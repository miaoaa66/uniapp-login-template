## 1. 极简留白 Minimalism

**定义**：以留白与字重层级代替一切装饰，界面只剩文字、输入框与一条分割线。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#FFFFFF` / 正文 `#111111` / 次级文字 `#8A8A8A` / 分割线 `#E8E8E8` / 强调 `#111111` |
| 字体气质 | 无衬线（苹方 / 思源黑体），标题 28–32px、字重 500，正文 14px、字重 400，字距 +0.5px |
| 质感与图形语言 | 零阴影、零渐变；输入框仅 1px 下边框，聚焦时变 1px `#111111`；圆角 0–4px；错误仅用红色文字，不加底色 |
| 动效建议 | 入场：整块自上淡入 200ms；聚焦：下边框 2px 由中间向两端展开；按钮：无位移，仅背景由 `#111` 到 `#333` 的 120ms 过渡 |
| 适用与落地 | 工具型、企业后台。落地风险最低，全平台一致；注意留白比例需 8pt 栅格严格对齐，否则易显廉价 |

## 2. 瑞士国际网格 Swiss Style

**定义**：严格栅格 + 左对齐无衬线 + 单一高饱和红，信息以秩序感取胜。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#F5F3EF` / 正文 `#111111` / 次级 `#6E6E6E` / 强调红 `#E2231A` / 栅格线 `#111111` |
| 字体气质 | 无衬线（Helvetica / Inter），标题 flush-left、字重 700、字距 −1px 收紧；标签 11px 全大写 + 字距 1.5px |
| 质感与图形语言 | 可见的 12 栏基线网格；标题上方一条 1px 黑色通栏线；红色仅用于「提交」按钮与必填标记，面积占比 <5% |
| 动效建议 | 入场：标题按行 60ms 逐行上浮；聚焦：标签同步移动到输入框上方（floating label）；按钮：hover 时黑色描边 1px 变 2px |
| 适用与落地 | 品牌官网、设计机构。栅格需以 `%` 或 `calc` 实现以适配不同屏宽；小程序端无风险 |

## 3. 杂志编辑风 Editorial

**定义**：把登录页当作杂志内页排版，衬线大标题承担情绪，小字标签承担信息。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#FAF7F2` / 正文 `#1C1A17` / 次级 `#7A7268` / 强调 `#9B2C1F` / 细线 `#D9D2C6` |
| 字体气质 | 标题用衬线（思源宋体 / Noto Serif），32–40px、字重 700、行高 1.15；副标用无衬线小字 12px + 字距 0.8px |
| 质感与图形语言 | 上下双细线夹住「本期主题」式眉标；图片或插画占上半屏 45%；正文分段首行缩进 2 字符；圆角 0 |
| 动效建议 | 入场：大标题 clip-path 自下而上揭示 400ms，副标延后 100ms；聚焦：输入框下方细线由左向右生长；按钮：文字字距在 hover 时 +0.5px |
| 适用与落地 | 内容型产品、媒体会员。`clip-path` 在部分安卓 WebView 需加 `-webkit-` 前缀，建议同时提供纯 opacity 降级 |

## 4. 玻璃拟态 Glassmorphism

**定义**：半透明磨砂面板浮在彩色光斑背景之上，靠模糊与透光建立层次。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#101A2B`（叠加 `#6D5BFF`、`#29D2C4` 两团光斑）/ 面板 `rgba(255,255,255,0.12)` / 正文 `#FFFFFF` / 次级 `rgba(255,255,255,0.65)` / 描边 `rgba(255,255,255,0.24)` |
| 字体气质 | 无衬线（SF Pro / 苹方），标题 26px 字重 600，正文 14px；浅色文字需保证对比度 ≥ 4.5:1 |
| 质感与图形语言 | `backdrop-filter: blur(24px) saturate(160%)`；面板圆角 20px + 1px 白色半透明描边；右上角一道 45° 高光；背景光斑用 `radial-gradient` 而非图片 |
| 动效建议 | 入场：面板 scale 0.96→1 + opacity，300ms；聚焦：描边由 0.24 提到 0.6 并外发光；按钮：内部高光沿对角线扫过 600ms |
| 适用与落地 | 科技品牌、影音类。**小程序端风险高**：安卓微信 `backdrop-filter` 支持不稳定，必须准备 `rgba(16,26,43,0.82)` 不透明降级底色，否则文字不可读 |

## 5. 新拟态 Neumorphism

**定义**：控件与背景同色，仅靠一明一暗两个方向的内外阴影塑造「压出来」的立体感。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#E6E9F0` / 控件同底 / 正文 `#4A5568` / 强调 `#5B6CFF` / 暗阴影 `#C3C9D6` / 亮阴影 `#FFFFFF` |
| 字体气质 | 无衬线（Nunito / 苹方圆体方向），标题 24px 字重 700，正文 14px 字重 500，整体偏圆润 |
| 质感与图形语言 | `box-shadow: 6px 6px 12px #C3C9D6, -6px -6px 12px #FFFFFF`；输入框用 inset 同款；圆角 16px；禁用零描边 |
| 动效建议 | 入场：整卡阴影从 0 半径扩散到 12px，400ms；聚焦：输入框由 inset（凹陷）切到 outset（凸起）；按钮：按下时反转为 inset |
| 适用与落地 | 智能硬件、健康类。**可用性风险**：低对比度导致输入区边界不清，需保证 inset 阴影深度 ≥ 6px 且边框对比度不低于 3:1；不支持 `backdrop-filter` 的端反而更稳 |

## 6. 粘土拟态 Claymorphism

**定义**：把界面做成厚实的橡皮泥块，超大圆角 + 内部双层阴影 + 糖果色。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#FFF5F0` / 主块 `#FF7B54` / 辅块 `#6C63FF` / 正文 `#3D2C29` / 高光 `#FFFFFF` |
| 字体气质 | 圆体无衬线（Baloo / 站酷快乐体方向），标题 28px 字重 800，正文 15px 字重 500，行高 1.6 |
| 质感与图形语言 | 圆角 28–32px；`box-shadow: inset -6px -6px 12px rgba(0,0,0,.18), inset 6px 6px 12px rgba(255,255,255,.35), 0 12px 24px rgba(255,123,84,.25)`；色块之间留 16px 缝 |
| 动效建议 | 入场：色块按 80ms 间隔逐个「弹入」（scale 0.8→1.06→1）；聚焦：输入块轻微鼓起；按钮：按下时下沉 3px 并加深内阴影 |
| 适用与落地 | 儿童教育、宠物、新手引导。内阴影层数多，低端安卓设备滚动可能掉帧，建议限制同时动画元素 ≤ 6 个 |

## 7. 有机自然 Organic

**定义**：奶油底色 + 植物绿 + 曲线分割，传递温和、无压迫的呼吸感。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#F7F4EC` / 主绿 `#6B8F71` / 深浅绿 `#3F5D45` / 正文 `#2F3A2E` / 次级 `#8A9683` / 线 `#DDE5D5` |
| 字体气质 | 无衬线（思源黑体 / DM Sans），标题 28px 字重 600、行高 1.3；可搭配一个手写体作为标签点缀 |
| 质感与图形语言 | 大面积弧形分割（`border-radius: 50% 50% 0 0 / 120px 120px 0 0`）；叶片 / 波纹线性插画；圆角 20px；阴影极淡 `0 8px 24px rgba(63,93,69,.08)` |
| 动效建议 | 入场：弧形色块自下向上推入（translateY 24px + opacity）；聚焦：输入框背景由 `#F7F4EC` 变 `#FFFFFF` 并浮现 1px 绿边；按钮：树叶状涟漪扩散 |
| 适用与落地 | 农业生鲜、健康、可持续品牌。曲线用 `border-radius` 百分比实现即可，无需 SVG 滤镜，全端安全 |

## 8. 粗野主义 Brutalism

**定义**：故意反精致——超粗字、纯黑硬边框、荧光原色、零圆角、可见的结构线。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#FFFDF4` / 正文 `#000000` / 强调 `#FF4D00` / 辅色 `#00E0C6` / 边框 `#000000` |
| 字体气质 | 几何无衬线或等宽（Archivo Black / Space Mono），标题 40–48px、字重 900、字距 −2px、可全大写；正文 14px 等宽 |
| 质感与图形语言 | 3px 纯黑边框 + 8px 硬阴影（`box-shadow: 8px 8px 0 #000`）；圆角 0；按钮按下时阴影收缩为 4px 并位移 4px；允许出现黑色警示条纹与裸表格线 |
| 动效建议 | 入场：无缓动（`ease-out` 0ms 延迟但时长 120ms），硬切；聚焦：边框由 3px 变 5px 并转为 `#FF4D00`；按钮：按下即位移，无过渡曲线 |
| 适用与落地 | 潮流品牌、活动页。纯 CSS 能力即可实现，性能与兼容性都很好；需注意 3px 边框在小屏会挤压内容，最小边距留 16px |

## 9. 孟菲斯 Memphis

**定义**：高饱和几何拼贴 + 黑色描边 + 波点波浪，刻意制造「不规整」的活泼感。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#FFF9EC` / 红 `#FF5F5F` / 黄 `#FFD166` / 蓝 `#4CC9F0` / 紫 `#8338EC` / 描边 `#141414` |
| 字体气质 | 无衬线粗体（Poppins / 阿里巴巴普惠体方向），标题 30px 字重 800，正文 14px 字重 500 |
| 质感与图形语言 | 2px 黑描边 + 4px 硬阴影；圆角 12px；背景散落波点、折线、半圆、十字等几何装饰（建议用 `radial-gradient` 重复图案做波点，避免多图请求） |
| 动效建议 | 入场：装饰元素带 6°–12° 随机初始旋转各就位（300ms 交错）；聚焦：输入框描边闪一下黄色；按钮：hover 时整体旋转 −2° |
| 适用与落地 | 校园、活动运营。注意「装饰不得压在输入框上」，装饰层统一 `pointer-events: none` 且 z-index 低于表单 1 层 |

## 10. 包豪斯 Bauhaus

**定义**：以红、黄、蓝三原色与圆、方、三角三种基本形构成画面，强调功能与构成的统一。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#F2EDE4` / 红 `#D93A28` / 黄 `#F2B300` / 蓝 `#1F4E9C` / 黑 `#111111` |
| 字体气质 | 几何无衬线（Futura / Josefin Sans 方向），标题 34px 字重 700，小写字距 +2px；可用竖排或斜置打破呆板 |
| 质感与图形语言 | 基本形直接作为背景构成元素，允许出血到屏幕边缘；块面纯色无渐变；圆角 0 或全圆（`50%`）二选一，不用中间值 |
| 动效建议 | 入场：圆 / 方 / 三角按 120ms 依次滑入构图位置；聚焦：输入框右侧出现一个蓝色小圆点；按钮：红底方块，点击时黄底闪 80ms |
| 适用与落地 | 设计工具、艺术教育。构成元素应作为独立绝对定位层，避免影响表单流式布局；全端安全 |

## 11. 赛博霓虹 Cyberpunk

**定义**：深黑底 + 青粉双色霓虹描边 + 扫描线与故障字，营造夜间电子氛围。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#08060F` / 面板 `#11101C` / 主霓虹 `#00F0FF` / 副霓虹 `#FF2E97` / 正文 `#E8ECFF` / 网格线 `rgba(0,240,255,0.12)` |
| 字体气质 | 等宽或技术感无衬线（JetBrains Mono / Oxanium），标题 26px 字重 700 + 字距 2px，标签全大写 |
| 质感与图形语言 | 1px 霓虹描边 + `box-shadow: 0 0 12px` 外发光；背景网格用 `repeating-linear-gradient`；扫描线用半透明横条叠加（`opacity .06`）；角落切角用 `clip-path: polygon()` |
| 动效建议 | 入场：标题做 200ms 故障位移（随机 translateX ±2px）；聚焦：描边呼吸发光 1.6s 循环；按钮：点击时一道亮线自上而下扫过 |
| 适用与落地 | 游戏、电竞。`text-shadow` 多层发光在低端机上开销明显，建议限制在标题层；避免使用 `filter: blur` 做大面积发光 |

## 12. OLED 纯黑

**定义**：纯黑背景最大化熄灭像素，只保留一个荧光强调色与克制的灰阶层级。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#000000` / 面板 `#0D0D0D` / 正文 `#EDEDED` / 次级 `#8C8C8C` / 强调 `#A3FF12` / 分割线 `#1F1F1F` |
| 字体气质 | 无衬线（Inter / 苹方），标题 28px 字重 600，正文 15px 字重 400；不使用纯白 `#FFFFFF` 以降低暗环境眩光 |
| 质感与图形语言 | 面板与纯黑之间仅用 `#1F1F1F` 1px 描边区分，无阴影（阴影在纯黑上不可见）；圆角 12px；强调色仅用于主按钮与聚焦环 |
| 动效建议 | 入场：逐级 8% 亮度递增（`#000 → #0D0D0D → 内容`）120ms 三级；聚焦：1px 荧光环外扩 2px；按钮：无渐变，仅亮度提升 12% |
| 适用与落地 | 极客工具、开发者。全端最稳，且 OLED 屏省电；需同步把 `pages.json` 对应页面的 `navigationBarBackgroundColor` 设为 `#000000` 与 `navigationBarTextStyle: white`，否则顶部会露出白条 |

## 13. 蒸汽波 Vaporwave

**定义**：粉紫渐变天空 + 透视网格地平线 + 罗马雕像 / 日文假名等怀旧符号，甜腻而失真。

| 字段 | 内容 |
| --- | --- |
| 色板 | 底 `#1A0B2E` / 粉 `#FF6AD5` / 紫 `#C774E8` / 蓝紫 `#8795E8` / 亮蓝 `#94D0FF` / 正文 `#FFFFFF` |
| 字体气质 | 装饰无衬线或复古衬线（可对标题做 3D 挤出效果），标题 32px、字距 +1px；辅以日文假名或英文全大写小字 |
| 质感与图形语言 | 天空用 4 色 `linear-gradient`；地平线以下用 `repeating-linear-gradient` 做透视网格；叠加一层扫描线与轻微噪点（`opacity .05`）；圆角 8px |
| 动效建议 | 入场：标题自下而上「升起」并带 2px 色差（品红/青）；聚焦：网格背景缓慢向下平移 8s 循环；按钮：粉到紫的渐变位移 |
| 适用与落地 | 潮流社区、复古音乐。色差效果用双 `text-shadow` 模拟即可，不要用 `mix-blend-mode`（小程序端支持差）；动态背景需可暂停 |

## 14. Y2K 千禧铬银

**定义**：模仿 2000 年前后的金属质感与气泡高光，冷银 + 荧光点缀。

| 字段 | 内容 |
| --- | --- |

## 选用建议

- **零风险先做**：1 极简留白、2 瑞士网格、8 粗野主义、12 OLED 纯黑、19 工业机械 —— 纯 CSS 静态能力，全端表现一致。
- **有现成参照**：15 像素 8-bit，直接对齐 `pages/login92`–`login105` 的 `style.scss` 写法。
- **需降级方案**：4 玻璃拟态（安卓微信 `backdrop-filter`）、3 杂志编辑（`clip-path` 前缀）、18 新中式（`writing-mode`）、20 HUD（`clip-path` 兜底）。
- **性能敏感**：6 粘土拟态、11 赛博霓虹、13 蒸汽波 —— 阴影层数或动态背景较多，需限制动画元素数量。
